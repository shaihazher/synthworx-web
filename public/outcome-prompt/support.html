Find or restore a pack

Look for the license key email from Dodo Payments. Open “Already have a pack key?” below the web editor and paste the key. You can use it on another browser or return to a previous pack the same way. The remaining balance belongs to the key. If the email is missing, check spam or send support your receipt number.

Use the free skill

Download the plugin ZIP and use your agent’s local plugin importer if it accepts Codex-format plugins. For agents that support the Agent Skills format, extract the ZIP and add the included skills/rewrite-prompts folder to your agent’s skills directory. For a single Codex project, use .agents/skills/rewrite-prompts in that project. Reopen the agent and say “Turn on Outcome Prompt for this chat.”

For one rewrite, ask “Use Outcome Prompt to rewrite this request” followed by your draft. To end ongoing rewrites, say “Turn off Outcome Prompt.”
