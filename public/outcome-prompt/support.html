Find or restore a pack

Look for the license key email from Dodo Payments. Open “Already have a pack key?” below the web editor and paste the key. You can use it on another browser or return to a previous pack the same way. The remaining balance belongs to the key. If the email is missing, check spam or send support your receipt number.

Use the free skill

Download the plugin ZIP and extract it. The skill is the skills/rewrite-prompts folder inside.

Install in a Codex project

  1. Create an .agents/skills folder in the project where you want to use the skill, if it doesn’t already exist.
  2. Copy the entire rewrite-prompts folder into it. The skill file will be at .agents/skills/rewrite-prompts/SKILL.md.
  3. Start a new Codex chat in that project. Type $ and select rewrite-prompts. Send $rewrite-prompts with the draft you want rewritten.

Install in another agent

Copy the rewrite-prompts folder into the skills directory for an agent that supports Agent Skills. If your agent imports Codex-format plugins, use its plugin importer with the extracted folder.

To keep rewriting drafts in the same chat, invoke the skill and say “Turn on Outcome Prompt for this chat.” Say “Turn off Outcome Prompt” to end the session’s rewrites.
