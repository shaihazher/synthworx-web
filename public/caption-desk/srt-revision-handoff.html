Before you send the fix list.

Keep the current caption export and the exact picture master together. A cue number can move when someone inserts a line.

Identify the revision

Record a title alias, picture cut, language and SRT revision. Keep the prior export and record a file fingerprint when two exports have the same name. A matching fingerprint identifies identical file bytes. The editor still needs to confirm the picture cut.

Write one actionable row per finding

In the fictional North River export, the row for cue 3 points to its start at 00:00:05,900 and the preceding cue’s end at 00:00:06,000. The next row points to a 480 ms caption at 00:00:09,000. Ask the editor to replay each boundary, make the timing change and return a newly labelled export.

Recheck the file and watch the cut

North River fell from six technical findings to two. That count tells the editor to open the current list. Recheck the revised file, then watch with sound to confirm dialogue, speaker changes and sync. Name the person signing off and the revision they watched.
